ALERTO: Development of a Location-Based Alert System for Enhancing Commuter and Driver Safety and Security

IOT AND CAPSTONE PROJECT

IoT Module & App Demo

TEAM MEMBERS:

Antonio, Princess Fiona • Dolera, Nathalie • Jomoc, Justine • Medilo, Mira Mae

MY ROLE:

Hardware Lead

Description

ALERTO combines an anti-theft bag device and a mobile application into one complete safety ecosystem. The system is designed to help commuters stay alert near their destinations, protect their personal belongings from theft, monitor travel safety, and provide continuous emergency connectivity.

Technologies & Components Used

Hardware & IoT Components: ESP32-S3 Microcontroller, Neo-M8N GPS Module, Air780E 4G LTE/GSM Module, MPU6050 Motion Sensor, Magnetic Reed Switch, LDR (Light) Sensor, Active Buzzer, Vibration Motor, and Custom 3D-Printed Enclosure.

Software, APIs & Cloud: C / C++ (Firmware), React Native & Expo, MapLibre Native & OpenFreeMap, Google Gemini AI (OCR), TomTom Traffic API, Next.js & Vercel (Admin), MongoDB Atlas & Prisma, iProg SMS Gateway, and Bluetooth Low Energy (BLE).

Ligtas Sundo: QR Code and RFID with SMS Notifications and Cloud Storage for Noveca Day Care Student Dismissal

PROJECT MANAGEMENT

Web Dashboard & RFID/QR Cards

Project Defense & Team

TEAM MEMBERS:

Antonio, Princess Fiona • Dolera, Nathalie • Jomoc, Justine • Medilo, Mira Mae

MY ROLE:

Frontend Developer

Description

Ligtas Sundo is a student arrival and dismissal monitoring system built for Noveleta Child Development Center (Noveca Day Care). By scanning dual QR Code and RFID student/fetcher ID cards, the system verifies authorized guardians in real time, logs attendance to the cloud, and dispatches instant SMS notifications to parents upon pickup.

Technologies & Components Used

Hardware & Identification: RFID Scanner Module, QR Code Camera Scanner, and Custom RFID/QR Student & Fetcher ID Cards.

Software, Frontend & Cloud: Responsive Web Teacher Dashboard (HTML, CSS, JavaScript), Real-Time Attendance & Fetcher Verification UI, SMS Notification Gateway Integration, and Cloud Database Storage.
